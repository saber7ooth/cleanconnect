# CleanConnect

Cleaner availability and roster management MVP.

## MVP

- Separate Cleaner and Roster Team portals
- Cleaner availability calendar
- Preferred cleaning locations
- Property size preferences
- Daily cleaning capacity
- Individual / Team of 2 / Team of 3
- Roster search and filters

## Product flow

Cleaner logs in → selects availability → chooses locations → selects property sizes → sets daily capacity → selects team type → saves availability → Roster Team sees and filters available cleaners → Roster Team assigns or schedules work.
